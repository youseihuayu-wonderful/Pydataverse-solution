# Repository maintenance instructions

This repository is an append-only engineering solution log for Dataverse and pyDataverse work.

After completing a relevant issue or pull-request task:

1. Append a new numbered solution to `Pydataverse-solution.md`.
2. Follow `SOLUTION_TEMPLATE.md`.
3. Include the problem, reproduction, investigation, operations, failures, communication, final code solution, validation, effect, and exact current status.
4. Clearly distinguish “implemented/tested” from “merged/released”.
5. Update the table of contents at the top of the main document.
6. Add small screenshots or diagrams under `assets/` when useful.
7. Never commit credentials, API tokens, passwords, cookies, private data, or oversized raw artifacts.
8. Use evidence-based wording and link to public issues, PRs, commits, and CI runs.
